# Daredevil

A dark, gritty Omarchy theme inspired by the Man Without Fear. Deep blacks, grunge grays, and striking crimson red accents.

* Install

```
   omarchy-theme-install https://github.com/YOUR_USERNAME/omarchy-daredevil-theme.git
```

## Color Palette

| Role       | Color                                                        |
|------------|--------------------------------------------------------------|
| Background | `#0e0c0c` |
| Foreground | `#d4d0cc` |
| Accent     | `#c42b2b` |
| Highlight  | `#1a1618` |
| Muted      | `#4a4646` |
| Bright Red | `#e04545` |
